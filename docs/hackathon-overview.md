## Rules that matter to us
- **One team can submit in only one track.** A person can be in only one submitting team.
- **AI coding tools are allowed with no restrictions** (Claude Code included), but must be
  **disclosed**: list them in Devpost "Built With" AND state in the README which parts were
  AI-assisted. Undisclosed use = misrepresentation. You must be able to explain your code if a judge asks.
- Judged by an industry expert panel against the track's own criteria.
- Further info is shared in the official Discord after registration — check it for updates/FAQs.

## Submission requirements (Devpost — all four required before the deadline)
1. **Project description** on the Devpost page: what you built, the problem, how it works.
2. **Public GitHub repo** with README: setup instructions, prerequisites/dependencies, how to run.
3. **Demo video** 3–10 min on YouTube (unlisted OK, private NOT OK). Must show the project running
   and explain the approach. English audio or English subtitles.
4. **Team info:** every member with real full name, own Devpost account, added to the submission
   (otherwise no certificate).
