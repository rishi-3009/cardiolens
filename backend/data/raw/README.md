# Put the dataset here

1. Open https://archive.ics.uci.edu/dataset/411/extention+of+z+alizadeh+sani+dataset
2. Click **Download** and unzip.
3. Put `extention of Z-Alizadeh sani dataset.xlsx` in this folder (you may rename it to `z_alizadeh_sani_extension.xlsx`).

Never edit this file by hand. Cleaning happens in code (`backend/src/data.py`).
